# ============================================================
# FNAF_RTS - Guía de formato de mapa v3
# ============================================================
#
# Cada línea es una instrucción. Los comentarios empiezan por '#'.
# El orden de las secciones importa: primero SECTOR, luego NODE,
# después LINK, y al final OFFICE.
#
# ============================================================
# SINTAXIS
# ============================================================
#
# SECTOR <id> <x> <y> "<nombre>"
#     Declara un sector en coordenadas mundiales (x, y).
#     El nombre visible va entre comillas dobles.
#
# NODE <id> <sector_id> <local_x> <local_y> <tipo>
#     Declara un nodo dentro de un sector. Las coordenadas son
#     relativas al sector (local_x, local_y), no al mapa global.
#     Tipos válidos:
#         NORMAL        - nodo común. Sirve para todo (home, respawn,
#                         waypoints, etc.). Puede tener varios
#                         animatrónicos encima.
#         OFFICE        - nodo único de la oficina. Uno solo por mapa.
#                         Solo se conecta a ENTRY_LEFT / ENTRY_RIGHT.
#         ENTRY_LEFT    - puerta izquierda de la oficina.
#         ENTRY_RIGHT   - puerta derecha de la oficina.
#
# LINK <a> <b>
#     Conexión bidireccional entre dos nodos.
#
# LINK <a> > <b>
#     Conexión direccional: solo se puede ir de <a> a <b>.
#
# OFFICE left <nodo>
# OFFICE right <nodo>
#     Define qué nodo es la puerta izquierda y cuál la derecha.
#     Los nodos deben ser de tipo ENTRY_LEFT y ENTRY_RIGHT
#     respectivamente.
#
# ============================================================
# REGLAS Y VALIDACIONES
# ============================================================
#
# 1) Todo nodo debe declarar un sector que YA exista arriba en el archivo.
#    No puedes usar un sector antes de declararlo.
#
# 2) Los IDs de sectores y nodos deben ser únicos.
#
# 3) Todo nodo debe tener al menos un LINK. Nada de islas.
#
# 4) Debe existir exactamente UN nodo de tipo OFFICE.
#    Si no hay ninguno, o hay más de uno, el mapa no carga.
#
# 5) El nodo OFFICE solo puede conectarse a ENTRY_LEFT o ENTRY_RIGHT.
#    Conectar la oficina a un NORMAL da error.
#
# 6) OFFICE left debe apuntar a un nodo de tipo ENTRY_LEFT.
#    OFFICE right debe apuntar a un nodo de tipo ENTRY_RIGHT.
#
# 7) Las coordenadas pueden ser cualquier entero (negativos incluidos).
#    El juego escala automáticamente al tamaño del panel.
#
# 8) Sectores con nodos muy juntos en el archivo se verán muy juntos
#    en pantalla. Deja 3-4 unidades de separación entre nodos contiguos.
#
# 9) Un mismo nodo puede ser HOME de un animatrónico y RESPAWN de otro,
#    o HOME y RESPAWN del mismo. Se define en Main.java, no aquí.
#    Los nodos que sean home o respawn de un animatrónico quedan
#    reservados SOLO para ese animatrónico.
#
# ============================================================
